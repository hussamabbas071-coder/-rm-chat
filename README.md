# RM — تطبيق تواصل خاص بين شخصين

دردشة نصية وصور ورسائل صوتية ومكالمات صوت وفيديو، كلها مشفّرة من طرف لطرف.

**المميزات:** علامات القراءة ✓✓ · «يكتب…» · متصل الآن / آخر ظهور · رسائل صوتية لحد دقيقتين ·
صور مضغوطة · حذف الرسالة عند الطرفين · فتح فوري وقراءة الرسائل بدون نت ·
المكالمة ترجع تتصل تلقائياً إذا تبدّلت الشبكة (واي فاي ↔ بيانات) · عداد استهلاك النت · 3 مستويات جودة ·
قلب الكاميرا · الشاشة تبقى شغالة وقت المكالمة.
يشتغل على آيفون كتطبيق من الشاشة الرئيسية، وما يحتاج App Store.

---

## شنو المحمي وشلون

| الشي | الحماية |
|---|---|
| الرسائل والصور | تتشفر على جهازك بـ AES-256-GCM قبل ما تطلع. Firebase (وحتى Google) يشوف بس كلام مشفّر ما ينقرا |
| مفتاح التشفير | ينشق من «كلمة سر التشفير» (PBKDF2 بـ 600 ألف دورة). ما تنرسل ولا تنحفظ بأي سيرفر |
| المكالمات | الصوت والصورة مشفّرة دائماً بـ DTLS-SRTP وتمر مباشرة بين الجهازين. بيانات ترتيب المكالمة مشفّرة بمفتاحكم كذلك |
| الدخول | حسابين بس. قواعد Firestore ترفض أي حساب ثاني، حتى لو أحد سوى حساب بمشروعكم |
| الصور | تتصغّر لتوفير النت، وتنمسح منها البيانات المخفية مثل موقع التصوير |
| الموقع | سياسة CSP وهيدرات أمان تمنع حقن الأكواد وفتح الموقع داخل مواقع ثانية |

**بصراحة:** ماكو شي محمي ١٠٠٪. أضعف نقطة دائماً هي الجهاز نفسه وكلمات السر. فخلي:
- كلمة سر الحساب قوية، وكلمة سر التشفير طويلة (جملة كاملة أحسن من كلمة).
- قفل الآيفون بـ Face ID أو رمز.
- لا تكتب كلمة سر التشفير بالتطبيق نفسه. اتفقوا عليها بمكالمة أو وجهاً لوجه.

| الوضع | صوت | فيديو |
|---|---|---|
| توفير (الافتراضي) | ~0.15 MB/دقيقة | ~1.2 MB/دقيقة |
| عادي | ~0.2 MB/دقيقة | ~2.7 MB/دقيقة |
| عالي | ~0.25 MB/دقيقة | ~7.5 MB/دقيقة |

## خطوات التشغيل (تحتاج كمبيوتر حوالي ٢٠ دقيقة، ومرة وحدة بس)

### ١) مشروع Firebase
1. ادخل https://console.firebase.google.com وسوّي مشروع جديد (تكدر تطفي Google Analytics).
2. **Build > Authentication > Get started > Email/Password > Enable**.
3. **Users > Add user**: سوّي حسابين (إلك وللطرف الثاني) بكلمات سر قوية.
   انسخ الـ **User UID** مال كل واحد.
4. **Build > Firestore Database > Create database**: اختار **Production mode**، والمنطقة `europe-west` (قريبة عليكم).
5. **Project settings (الترس) > Your apps > أيقونة الويب `</>`**: سجّل تطبيق ويب، وانسخ قيم `firebaseConfig`.

> الخطة المجانية (Spark) تكفي، وما يحتاج Storage ولا بطاقة دفع.

### ٢) عدّل الملفات
- `public/config.js`: الصق `firebaseConfig`، وحط الـ UID بـ `ALLOWED_UIDS`، وحط الـ UID نفسها كمفاتيح بـ `NAMES` مع الأسماء.
- `firestore.rules`: بدّل `UID_1` و `UID_2` بنفس الـ UID.

### ٣) النشر
على الكمبيوتر (يحتاج Node.js):
```bash
npm install -g firebase-tools
firebase login
cd rm
firebase use --add        # اختار مشروعك
firebase deploy
```
يطلع لك رابط مثل `https://اسم-مشروعك.web.app`.

### ٤) تقوية إضافية (مستحسن)
- **Google Cloud Console > APIs & Services > Credentials**: افتح الـ API key وقيّده بـ **Websites** واكتب دومينك `https://اسم-مشروعك.web.app/*`.
- **Authentication > Settings**: إذا موجود خيار **User actions**، طفّي **Enable create (sign-up)**.

### ٥) على الآيفون (للجهازين)
1. افتح الرابط بـ **Safari** (لازم Safari مو Chrome).
2. زر المشاركة ⬆️ > **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.
3. افتح «RM» من الشاشة الرئيسية وسجّل دخول.
4. **أول واحد يفتح** يختار كلمة سر التشفير (12 حرف أو أكثر) ويكتبها مرتين. **الثاني** يكتب نفس الكلمة.
   الكلمة تنقفل بالسيرفر وما تتغير. إذا تريد تبدّلها: احذف `rooms/main/meta/verifier` من Firestore Console (والرسائل القديمة ما راح تنقرا بعدها).
5. أول مكالمة أو رسالة صوتية راح يطلب إذن المايك والكاميرا. وافق.

## سيرفر TURN (إذا المكالمة ما تتصل)

بعض شبكات الموبايل، خصوصاً بالعراق، تمنع الاتصال المباشر بين الجهازين. إذا طلع لك «تعذر الاتصال»:
1. سوّي حساب TURN مجاني أو رخيص، مثل **Metered.ca** أو **Cloudflare Realtime TURN**.
2. انسخ بياناته (host, username, credential) إلى `ICE_SERVERS` بملف `config.js` وانشر مرة ثانية.

الصوت والصورة يبقون مشفّرين حتى لو مرّوا من TURN. السيرفر ينقلهم بس، وما يكدر يفتحهم.

## أشياء لازم تعرفها عن الآيفون

- **المكالمة ترن بس إذا التطبيق مفتوح** عند الطرف الثاني. آيفون يوقف تطبيقات الويب من تنسد، فما تكدر ترن وهي مسدودة.
  الحل العملي: ابعث رسالة «أتصل؟» أولاً.
- حتى ترن المكالمة والتطبيق مسدود مثل واتساب، تحتاج تطبيق iOS حقيقي (CallKit + PushKit). وهذا يحتاج Mac وحساب Apple Developer بـ 99$ بالسنة. يكدر يكون مرحلة ثانية.
- **حذف رسالة:** ضغطة طويلة على رسالتك.
- **زر القفل 🔒:** يمسح المفتاح من الجهاز، فإذا أحد مسك تلفونك ما يكدر يقرا شي بدون كلمة سر التشفير.
